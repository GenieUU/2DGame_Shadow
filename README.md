## Shadow: 2D 플랫포머 액션 게임

##### 게임 소개
-게임 이름: Shadow

-장르: 2D 플랫폼 액션 게임

-제작환경: Unity 2022.3.59f1 버전


##### 게임 내용
해당 게임을 플레이 할 경우 검정색과 하얀색밖에 없는 도트 이미지들 사이에서 빨간 망토를 두르고 있는 플레이어가 눈에 띄게 보입니다. 

이 게임 속 플레이어는 동화 ‘빨간 망토’의 내용을 모티브로 하고 있습니다. 

게임 속 주인공은 마치 원작 동화에서 할머니 집으로 향하던 빨간 망토 소녀처럼, 각종 위협을 피해가며 길을 나아가야 하며, 플레이어는 이를 도와 빨간 망토를 쓴 주인공을 방향키를 통해 조작하여, 어두운 숲 속의 장애물과 몬스터를 피해 도착 지점까지 안전하게 이동해야 하는 게임입니다.

플레이어는 이동과 점프, 공격을 통해 장애물과 몬스터를 피하거나 제거할 수 있으며, 게임의 최종 목표 지점은 원작 속 할머니 집에 도착하는 장면에서 착안하여‘문’ 형태의 오브젝트로 표현하였습니다.
